Demonstrated today

  • Upstream bootloader code at pinned commits, compiled with pinned toolchains on every run
  • Ephemeral signing keys; real binaries booted and updated in Renode
  • Negative tests: tampered image, wrong key, old bootloader receiving the new image
  • Deterministic V1.2 engine with golden-hash regression tests
  • Re-evaluations as new runs with a parent reference; history immutable
  • Evidence pack download and strict release-gate CLI with engine replay

Not claimed

  • Results on physical silicon: this is emulation
  • Power-loss / interrupted-update safety: stays UNKNOWN
  • Support for arbitrary or proprietary firmware: 2 configurations only
  • Certification or regulatory compliance: non-official assessment
  • Semantic truth of every AI sentence: checks cover IDs and verdict labels
